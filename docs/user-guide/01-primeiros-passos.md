# Guia 01 — Primeiros Passos

## Como fazer login

Acesse o portal pelo link fornecido pela Tallpa Solutions (ex: `wave.tallpa.com.br`). Na tela de login, informe seu **e-mail** e **senha** e clique em **Entrar**.

Se esqueceu a senha, clique em **Esqueci minha senha**, informe seu e-mail e aguarde o link de redefinição na caixa de entrada.

## Primeiro acesso

Ao ser cadastrado pelo administrador, você receberá um e-mail com um link de **primeiro acesso**. Clique no link, defina sua senha pessoal e faça login normalmente a partir daí.

## Mapa do menu lateral

| Item | O que faz |
|---|---|
| Dashboard | Visão geral com KPIs do mês: visitas, payouts, improdutivas e margem |
| Equipe | Lista de gestores cadastrados no tenant |
| Técnicos | Cadastro e consulta de técnicos de campo |
| Uploads | Envio e acompanhamento das planilhas de OSs |
| Motivos | Classificação dos motivos de não-conclusão das visitas |
| LPU | Configuração da Lista de Preços Unitários (regras de payout) |
| OSs | Consulta e acompanhamento das Ordens de Serviço |
| Pagamentos | Detalhe de payouts calculados por visita |
| Financeiro | Visão financeira consolidada (receita, custo, margem) |
| Fechamento | Ciclo mensal de aprovação e pagamento |
| Ajuda | Esta central de ajuda |

## Atualizar perfil e senha

No menu lateral, clique em **Equipe** → encontre seu usuário → edite nome e e-mail. Para trocar a senha, acesse **Equipe → seu usuário → Alterar senha**.
