# Guia 04 — Classificar Motivos

## Por que classificar importa

Quando uma visita é improdutiva (não concluída), o sistema cria automaticamente um **motivo** com o texto vindo da planilha. Enquanto o motivo não for classificado, o payout da visita fica pendente.

A categoria do motivo determina:
- Se o técnico recebe o payout de improdutiva
- Se o valor "deixado na mesa" é contabilizado
- Quem foi responsável pela falha

## As 4 categorias

| Categoria | Quando usar |
|---|---|
| **Falha do técnico** | O técnico não compareceu, chegou atrasado ou cometeu erro operacional |
| **Falha do cliente** | O cliente não estava presente, cancelou ou não deu acesso |
| **Falha externa** | Problema de infraestrutura, clima, terceiros ou situação fora do controle |
| **Cancelamento pelo cliente** | O cliente solicitou cancelamento formal da OS |

## Passo a passo para classificar

1. No menu lateral, clique em **Motivos**
2. Clique no chip **Pendente** para filtrar só os não classificados
3. Clique em **Editar** no motivo que deseja classificar
4. Selecione a categoria adequada
5. Marque **Paga improdutiva** se o técnico deve receber mesmo sem ter concluído
6. Opcionalmente, informe um **valor fixo** de improdutiva (se vazio, usa a regra da LPU)
7. Clique em **Salvar motivo**

O payout da visita é recalculado automaticamente após salvar.

## Dica

Quanto mais rápido os motivos forem classificados após o upload da planilha, mais preciso estará o fechamento mensal. Deixar muitos motivos pendentes no final do mês pode atrasar a aprovação.
